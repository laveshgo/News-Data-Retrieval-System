# News-Data-Retrieval-System
Building a Contextual News Data Retrieval System

A backend system that can fetch and organize news articles from a
data source, simulating different API functionalities, and enrich these articles with LLM-generated insights.

How to run - 

1. run this command to export google creds in terminal 
   `export GOOGLE_APPLICATION_CREDENTIALS="YOUR_SERVICE_KEY"`
2. run this command to build maven project
   `mvn clean install`
3. run this command to start your spring project
   `java -jar rest/target/rest-1.0.0.jar`
